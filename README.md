## SteamMewks

**A creative laboratory for games, tools, embedded systems and experimental works.**

SteamMewksは、ゲーム、Webツール、組み込み開発、試作システム、物理作品などを横断して制作する個人制作ブランドです。

分野を固定するのではなく、

**「思いついた仕組みを、実際に動くものとして形にすること」**

を重視しています。

完成品だけでなく、プロトタイプ、旧版、実験コード、失敗から生まれた仕組みも、制作の一部として残していきます。

### 心の天気予報 / Mental Weather Forecast

毎日の気分や疲労を「天気」のように記録し、あとからゆるく振り返るためのブラウザアプリです。

主な機能：

- 気分・疲労の記録
- カレンダー表示
- 直近1週間の簡易分析
- CSV / JSON書き出し
- PWA対応
- SteamMewks作品との連動要素

Repository:  
https://github.com/SteamMewks/Mental-Weather-Forecast

## Embedded Development

今後、Raspberry Pi、Raspberry Pi Pico、PICマイコンなどを利用したコードや試作も公開していく予定です。

扱う内容は、単なるサンプルコードだけでなく、

- センサー制御
- 入出力制御
- 小型機構
- インタラクティブ作品
- ゲームや物理作品との連動
- 実験的な制御システム

などを想定しています。

---

## Development Style

SteamMewksでは、完成したコードだけを成果とは考えていません。

試作段階で生まれた仕組みや、後の作品へ引き継がれたアイデアも重要な制作記録です。

そのため、一部のリポジトリでは、

- 旧バージョン
- プロトタイプ
- 実験実装
- 開発終了作品

なども保存・公開しています。

## About the Laboratory

SteamMewksは、特定のジャンルや技術分野に収まることを目的としていません。

ゲームを作るためにAIが必要ならAIを作り、  
物理作品を動かすためにマイコンが必要ならマイコンを使い、  
記録ツールが必要ならWebアプリを作る。

必要な技術を組み合わせながら、一つの仕組みとして完成させることを目指しています。
